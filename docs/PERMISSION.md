下载可以免费，但使用必须先获得权利人的明确书面许可。个人学习、免费课堂和非商业测试都不自动豁免。商业用途不在本版本许可范围内。

## 怎么申请

在本仓库建立 Issue，选择“非商业使用许可申请”，或者复制下面的格式。等待仓库维护者代表项目权利人明确批准后再运行或部署。申请成功提交、下载、Star、Fork 及程序中的确认按钮都不等于批准。

```text
申请使用版本：5.0.0 / public.1
使用场景：例如个人非商业自学 / 免费课堂演示
是否涉及收费、广告、商业推广或经营用途：否
希望使用的设备/人数范围：
希望使用的期限：
是否需要修改、部署或再分发：如需要，请单独说明；默认不申请这些权利
我确认：申请中不包含个人敏感信息，批准前不开始使用。
```

GitHub 账号由 Issue 平台显示，不需要再提供邮箱、电话、真实姓名、学校/单位详细名称、身份证明或学生身份信息。若场景必须涉及敏感信息，先只提出需要非公开渠道的请求，不把信息贴到公开 Issue。
