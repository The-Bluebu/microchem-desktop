# 安装、校验与故障处理

## 要求

Windows 10/11 x64、可用 WebGL 与正常显卡驱动。只验证本次 Windows 桌面包，不承诺所有远程桌面、虚拟机、显卡或高 DPI 配置都表现一致。建议保留约 1 GB 可用空间。

## 校验下载

把软件包和同一 Release 的 `SHA256SUMS.txt` 放在一起，在该目录运行：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\Microchem-Desktop-5.0.0-public.1-win-x64.zip'
Get-FileHash -Algorithm SHA256 -LiteralPath '.\Microchem-Desktop-5.0.0-public.1-win-x64.exe'
Get-Content -LiteralPath '.\SHA256SUMS.txt'
```

逐一比对对应文件的 SHA-256。校验值只能证明与你信任的发布附件一致，不是代码签名、无毒认证或安全保证。

## 便携版

取得使用许可后，完整解压便携 ZIP，进入 `Microchem-Desktop`，打开 `微观化学演示台.exe`。所有 DLL、PAK、`resources` 等文件必须保持同一目录结构。不要在压缩文件中启动，不要只发一个 EXE。

## 安装版

取得许可后运行安装 EXE。安装向导包含许可条款，可选择安装目录；首次安装默认优先使用 D 盘的应用目录，已有安装应尊重现有位置。程序没有代码签名，若系统提示未知发布者，应检查来源、校验值和安全软件判断，不要关闭防护。

本机已验证的便携运行、内置计算和导出不等于所有电脑的安装/卸载流程都已验证。正式面向更多用户分发前，建议在另一台干净 Windows 电脑完成安装与卸载试验。

## 数据和备份

公开分发版优先使用 `D:\MicrochemDesktop\Data`；D 盘不存在或不可写时回退到系统应用数据目录下的 `MicrochemDesktop`。可从“文件 → 打开数据目录”查看实际位置。此目录是使用者自己的数据，不在下载包中。

本公开分发版与先前本机开发版的数据目录不同，不会自动读取开发版记录。需要迁移时，从旧版菜单导出可信备份，再在新版“文件 → 恢复学习记录”导入。同名记录会被替换，其他记录保留；先备份现有数据。

## 常见问题

| 现象 | 先做什么 |
| --- | --- |
| 缺少内置服务或页面资源 | 重新校验并完整解压；不要只复制 EXE |
| 模型空白或图形异常 | 更新正常来源的显卡驱动，确认 WebGL；比较本地会话与远程桌面 |
| 计算服务停止 | 退出程序后重新打开；查看“帮助 → 打开日志目录” |
| WebM 按钮不可用 | 当前设备不支持相应录制能力，先使用 PNG |
| 学习记录没有出现 | 核对菜单中的实际数据目录，必要时通过备份迁移 |
| 某结构待确认或有限制 | 阅读状态与来源限制，不据此推断已有完整实验模型 |

不要以删除整个学习数据目录作为常规排错手段。反馈前按 [隐私要求](FEEDBACK.md) 清理日志和截图。
