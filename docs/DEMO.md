# 实机演示素材说明

素材采集于 Windows 上真实运行的本次公开分发桌面程序。使用自动化工具执行真实点击、输入、拖动和模板切步，再从 Electron 页面捕获实际像素。素材不是 UI 设计稿，也未替换模型或伪造功能效果。

为保护隐私，仅捕获应用内容区域，不捕获整个桌面、系统任务栏、文件选择器、账号界面或含路径的“关于”对话框。采集使用新的独立 profile，与维护者正在使用的学习记录分离。示例只含内置课程、NaCl、ZnS、CCO 等非私人教学内容。

GIF 是真实操作过程的连续截图序列转制，按统一帧率呈现，节奏不代表性能基准或逐毫秒屏幕录像。视频是应用自身实际导出的 WebM，展示导出产物，不冒充全桌面录屏。
